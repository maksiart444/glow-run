# GLOW RUN

Неоновая аркада-лабиринт с тремя мирами. Работает в браузере на компьютере, Android и iPhone,
устанавливается на телефон как приложение и запускается без интернета.

*A neon maze arcade with three worlds. Plain HTML5 Canvas + JavaScript, no frameworks or build step.
Runs in any modern browser on desktop and mobile, installable as a PWA, works offline.*

## Особенности

- **Три мира** с собственным лабиринтом, героем, врагами, фоном, эффектами и музыкой:
  Cyber Glow (дрон-хакер против антивирусов), Deep Glow (рыбка-удильщик в глубинах океана),
  Forest Glow (светлячок в ночном лесу). Миры открываются по очереди, потом — бесконечный режим.
- **Четыре характера врагов**, у каждого своё поведение:
  - *Охотник* идёт к герою кратчайшим путём (поиск в ширину по клеткам);
  - *Перехватчик* целится туда, где герой окажется через несколько клеток;
  - *Патрульный* обходит свой участок и делает рывок, если видит героя по прямой;
  - *Хаотик* бродит непредсказуемо и оставляет замедляющие ловушки.
- **Отзывчивое управление:** движение строго по клеткам, поворот можно нажать заранее,
  свайпы на телефоне, стрелки и WASD на компьютере.
- **Графика:** неоновое свечение, анимированные персонажи, частицы, вспышки, всплывающие очки,
  тряска экрана. Всё тяжёлое рисуется заранее в отдельные холсты, поэтому игра идёт плавно и на телефонах.
- **Звук без файлов:** все эффекты и музыка синтезируются через Web Audio.
- **Прогресс сохраняется:** рекорд, открытые миры и настройки.

## Как запустить у себя

Нужен только Python (он есть почти везде) — он запускает простой локальный сервер:

```bash
python -m http.server 8000
```

Потом откройте в браузере `http://localhost:8000`.
Чтобы поиграть с телефона в той же Wi-Fi сети — `http://<IP компьютера>:8000`.

## Управление

| | Компьютер | Телефон |
|---|---|---|
| Движение | стрелки или WASD | свайп в любом месте экрана |
| Пауза | P или Esc | кнопка ❚❚ |
| Начать / дальше | Enter | кнопки на экране |

## Как устроен код

```
index.html        страница и экраны меню
style.css         оформление интерфейса
sw.js             работа без интернета (сервис-воркер)
manifest.json     установка на телефон
src/
  config.js       все настройки и баланс: скорости, таймеры, очки
  maze.js         лабиринт из текста, поиск пути, туннели
  entities.js     герой и враги, движение по клеткам, поведение врагов
  game.js         правила: очки, жизни, уровни, бонусы, состояния игры
  render.js       рисование лабиринта, персонажей и свечения
  fx.js           частицы, волны, всплывающие очки, тряска
  input.js        клавиатура и свайпы
  audio.js        синтезатор звуков и музыки
  ui.js           меню, панели, карточки миров
  storage.js      сохранение прогресса
  worlds/         три мира: цвета, карта, внешний вид персонажей
prototype/        первая версия на Python (pygame)
```

Лабиринт задаётся текстом: пишется левая половина, правая получается зеркально.
Баланс игры меняется в `src/config.js` без правок в остальном коде.

## Технологии

HTML5 Canvas 2D, JavaScript (ES-модули), CSS (glassmorphism, адаптивная вёрстка, safe-area для iPhone),
Web Audio API, Service Worker, Web App Manifest. Без фреймворков и сборщиков.
